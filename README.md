#  Voice AI College Assistant

A voice-enabled AI College Assistant using LSTM and Flask.

##  Features

- Voice-based interaction
- Text-based question answering
- LSTM-based intent classification
- Intent detection with confidence score
- Automated chatbot responses
- Flask web application

##  Technologies Used

- Python
- TensorFlow / Keras
- Flask
- NumPy
- HTML
- CSS
- JavaScript
- Speech Recognition
- LSTM
